# AI Automotive Market Intelligence Agent

An AI-powered market intelligence platform that collects, analyzes and summarizes automotive market information using Large Language Models, Retrieval-Augmented Generation and workflow automation.

## Project Goal

The goal of this project is to build an AI system that supports market intelligence and strategic decision-making in the automotive industry, with a focus on Chinese electric vehicle manufacturers.

## Focus Companies

- BYD
- Geely
- Zeekr
- NIO
- XPeng
- Li Auto
- Xiaomi Auto
- Tesla

## Core Features

- Automated news collection
- AI-generated article summaries
- Topic classification
- Competitor tracking
- Retrieval-Augmented Generation
- Streamlit dashboard
- AI chat interface
